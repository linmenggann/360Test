# 360°醫學人生｜走進臺南，走進生活 — 活動報名網頁

奇美醫院教學部「360°醫學人生｜走進臺南，走進生活」系列二日走讀工作坊視覺化線上報名網頁（健康台灣深耕計畫 D2-O1-5）。

## 活動資訊
- **活動名稱**：360°醫學人生｜走進臺南，走進生活
- **活動梯次**：
  - 第一梯次：115年10月17日(六) - 10月18日(日)
  - 第二梯次：115年11月14日(六) - 11月15日(日)
  - 第三梯次：115年11月21日(六) - 11月22日(日)
- **參加對象與每梯次名額**：西醫UGY (8人)、西醫PGY (10人)、醫事職類PGY (9人)、臨床教師 (8人)
- **集合時間**：第一天 08:50–09:00 ｜ 第二天 09:20–09:30
- **上車地點**：第一醫療大樓前方廣場
- **聯絡窗口**：林盟淦 教學行政管理員（06-281-2811 分機 57440 ／ `910632@chimei.org.tw`）

## 網頁特色
- **府城文化動態視覺**：融合廟宇燕尾脊與搖曳紅燈籠、四草綠色隧道竹筏巡河、後壁菁寮黃金稻浪、海棠鐵花窗圖騰、360°醫學人生互動羅盤與鎮北坊十站散步路線。
- **即時名額連動顯示**：於「身分」下拉式選單及側邊看板即時顯示各職類剩餘可報名人數，額滿自動鎖定。
- **旅責險專用資料獨立區塊**：「出生日期」與「身分證號」獨立分區呈現，提供民國年換算核對與證號遮罩保護。
- **表頭一鍵下載行程**：表頭配置「下載⾏程」按鈕，點擊即可下載完整 PDF 行程手冊。
